# Rechenzentrum-Projektimport

Der Einzelprojekt-Import bietet die Projekttypen PV, BESS, Hybrid, Rechenzentrum und Sonstiges.

Für Rechenzentrum werden PDF-Dokumente nach dem EMA-Standortdatenblatt strukturiert analysiert: Standort, Grundstück, Baurecht/Flächennutzung, Stromversorgung, Glasfaser und Ansprechpartner. Fehlende Angaben bleiben leer bzw. null; Werte werden nicht erfunden.

Die erkannten Werte werden vor einer weiteren Verarbeitung als editierbare Prüfansicht angezeigt.
