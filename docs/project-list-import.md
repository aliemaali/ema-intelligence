# Projektlisten-Import

Der Projektlisten-Import erkennt tabellarische PDF-, CSV- und TXT-Dateien und zeigt vor dem Speichern eine editierbare Vorschau.

Sicherheitsregeln:
- Keine automatische Anlage ohne Bestätigung.
- Jede Zeile kann abgewählt oder korrigiert werden.
- Leistungen werden aus MWp in kWp umgerechnet.
- Ungültige Zeilen und erkennbare Dubletten werden übersprungen.
- Bestehende Projekte werden nicht überschrieben.
- Maximal 500 Zeilen pro Import.
