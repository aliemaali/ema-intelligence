# Musterformulare

Die zentrale Vorlagenbibliothek ist unter `/musterformulare` erreichbar.

Funktionen:
- Upload bis 50 MB
- Kategorien für NDA, Anfrageformular, Vollmacht, Checkliste, Vertrag und Sonstiges
- sichere private Speicherung je Benutzer
- Download über zeitlich begrenzte signierte URL
- Entfernen über Archivierung
- direkter Zugriff über das Ordner-Symbol im Dashboard
