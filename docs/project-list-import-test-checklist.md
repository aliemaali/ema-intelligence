# Abnahmecheck Projektlisten-Import

- PDF mit mehreren Tabellenzeilen wird als Projektliste erkannt.
- Einzelprojekt-Dateien bleiben im bisherigen Importablauf.
- Vorschau ist editierbar und Zeilen sind abwählbar.
- MWp wird in kWp umgerechnet.
- Land wird auf Frankreich gesetzt.
- Dubletten und Zeilen ohne Leistung werden übersprungen.
- Ohne Bestätigung werden keine Projekte angelegt.
- Bestehende Projekte werden nicht verändert.
